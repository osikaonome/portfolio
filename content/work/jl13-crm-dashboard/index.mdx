<Section title="Overview">
  The internal CRM is how the team behind [MyAreaa](/work/myareaa) runs the platform: accounts, communities, wallets, transactions, KYC, RaiseMe fundraisers and social lounges, with real-time analytics on top. It has 50+ internal users and 99.2% uptime.

  Screens aren't shown publicly.
</Section>

<Section title="Single sign-on">
  Staff sign in with their Microsoft work accounts through Azure SSO, using MSAL in the browser, so access follows the company directory rather than separate passwords.
</Section>

<Section title="Analytics">
  I built the first version in React with ApexCharts for the dashboard's charts.
</Section>

<Section title="The Next.js rebuild">
  The dashboard is being rebuilt in Next.js with MSAL React, TanStack Query and TanStack Table, Zustand and Recharts, with spreadsheet export. My contributions to the rebuild include the transactions table and the dashboard view.
</Section>
